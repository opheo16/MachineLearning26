# Machine Learning 2026

## Project Overview
This repository contains laboratory work for the Machine Learning course.
The semester-long dataset is the Olist Brazilian E-Commerce Public Dataset.

## Dataset Location
Because raw data files are large, they are excluded from GitHub. 
Please download the dataset from Kaggle and place the CSV files inside the `data/raw/` directory.

## Folder Structure
- `data/raw/`: Original dataset files
- `data/processed/`: Cleaned datasets
- `notebooks/`: Jupyter notebooks
- `src/`: Python source code
- `reports/`: Reports and observations
- `figures/`: Generated plots
- `models/`: Trained models

## Lab 1
Lab 1 focuses on development environment setup, dataset loading, data inspection, and initial exploratory data analysis.
